# Icons

These SVG icons come unchanged from [Lucide](https://lucide.dev), version
1.72.0 of the `lucide-static` package, under the ISC license (some icons
derive from Feather, under the MIT license). Both licenses are in
[LICENSE](LICENSE).

FastEmu builds them into the binary (`src/assets.rs`) and draws them through
GPUI's asset source, so they take the text colour of their element.
