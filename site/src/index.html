MIDP 2.0 and the vendor APIs

Runs the CLDC 1.1 and MIDP 2.0 games of the 2000s: canvases, menus and forms, the game API, MMAPI sound, Nokia's UI API and Siemens' game classes.

Keypad or keyboard

Play with the keyboard, a touch keypad or both. Soft keys and arrows follow the key codes of the phone profile you pick.

terminal
$ fastemu run snake.jar --frames 300 --screenshot snake.png
loaded snake.jar (Retro Snake 1.0.0)
profile generic-240x320, 1 instance
ran 300 frames (101 drawn), 0 errors
saved snake.png (240x320)

A headless runner for testing

Run a game with no window for a set number of frames, press keys and touch the screen from a script, save a screenshot or every frame, and read the log. Use it in scripts and in CI.
