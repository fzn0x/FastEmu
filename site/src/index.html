Play J2ME games on modern computers and phones, many at once.

FastEmu is a free Java ME emulator written in Rust. It runs .jar and .jad games on Windows, Linux, macOS and Android.

Download GitHub

Keypad or keyboard

Play with the keyboard, a touch keypad or both. Soft keys and arrows follow the key codes of the phone profile you pick.

terminal
$ fastemu run snake.jar --frames 300 --screenshot snake.png
loaded snake.jar (Snake 1.2)
profile generic-240x320, 1 instance
ran 300 frames, 0 errors
saved snake.png (240x320)

A headless runner for testing

Run a game with no window for a set number of frames, save a screenshot and read the log. Use it in scripts and in CI.
